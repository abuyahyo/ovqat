# Ovqat — Eating Etiquette

A small app about the Islamic etiquette of eating: supplications before and after meals with authentic sources.

</div>

### Features
- Duas before and after eating with authentic hadith references
- Practical etiquette reminders

### Usage
```bash
git clone https://github.com/abuyahyo/ovqat.git
cd ovqat
# open index.html in a browser
```
